HD2 Player Capacity Native Bridge staging marker

This data folder intentionally contains no gameplay patch. Bingus Shared Loader
and Arsenal can merge data archives and dispatch Lua modules. The bundled
`mods/cainiao/` resources provide the shared capacity contract and menu adapter;
they do not replace native Session/Party/peer admission functions or allocate
executable trampolines. The native bridge payload is staged separately after
the exact-build, ABI and native-plan gates pass.
